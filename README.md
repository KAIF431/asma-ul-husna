# Asma-ul-Husna 3D (أسماء الله الحسنى) • 99 Beautiful Names of Allah

An interactive, responsive 3D web experience showcasing the 99 Beautiful Names of Allah, featuring dynamic 3D transformations (Sphere, Periodic Table Grid, Helix, and 3D Cube), Arabic calligraphy, Urdu meanings, audio recitation, and an interactive digital Tasbeeh counter.

---

## 🌟 Key Features

- **8 Majestic 3D Celestial Formations:**
  - `⚪ Sphere`: 3D Celestial Globe of all 99 divine names.
  - `🌙 Crescent`: Islamic Crescent Moon (Hilal) tapered 3D curve.
  - `🪐 Ring`: Torus Halo Ring / Celestial Orbit.
  - `🕌 Dome`: Sacred Islamic Dome (Gumbad) architectural vault.
  - `🌀 Helix`: Ascending Spiral Minaret / DNA double helix.
  - `🌌 Vortex`: Cosmic Galaxy Swirl (Tawaf formation).
  - `⊞ Table`: 11 × 9 Periodic Table Grid.
  - `🧊 Grid`: 5 × 4 × 5 3D Matrix Cube.
- **Silky-Smooth 360° Spherical Orbit Camera:**
  - Desktop: Mouse drag rotation + Scroll wheel zoom.
  - Mobile: 1-finger touch rotation + 2-finger pinch-to-zoom.
  - Inertial momentum damping & automatic gentle orbit toggle.
- **Royal Islamic Palette:** Deep midnight emerald green and radiant antique gold aesthetic with floating stardust particles.
- **Live Search & Filter:** Instant search by name, number, Urdu meaning, or English translation.
- **Detailed Modal Popup:**
  - Arabic Calligraphy with Tashkeel.
  - Urdu & English Meanings.
  - Quranic Ayat references.
  - Spiritual benefits (Fazilat) & explanation.
  - 🔊 Audio speech pronunciation in Arabic.
  - 📿 Digital Tasbeeh Counter with gentle audio chimes & mobile haptic vibration.

## 📁 Repository Structure

Everything is in a simple, flat structure (no complex subfolders):

```text
├── index.html       # Main HTML entry point (uses official CDN Three.js)
├── style.css        # Responsive Islamic styling & 3D card layout
├── app.js           # Three.js CSS3D & Spherical Orbit Controller
├── data.js          # Complete dataset of all 99 Names of Allah
└── README.md        # Project documentation
```

## 🚀 How to Deploy on GitHub Pages (Free Live Website)

1. Upload these files to your GitHub repository:
   - `index.html`
   - `style.css`
   - `app.js`
   - `data.js`
   - `README.md`
2. In your GitHub repository, click on **Settings** (top tab).
3. In the left sidebar, click on **Pages**.
4. Under **Branch**, select `main` (or `master`) and click **Save**.
5. Within 1 minute, GitHub will give you a live website link (e.g. `https://yourusername.github.io/your-repo-name/`)!
